# 📚 StudyNook - Collaborative Group Study Platform

**StudyNook** is a modern, full-stack collaborative web application designed to bring students and professionals together for group studying. It operates as an interactive platform where users can create study assignments, submit tasks, review peers' work, and filter assignments based on difficulty levels. Built with a focus on seamless user experience, secure authentication, and real-time feedback.

## 📝 Project Overview
Studying together is now more structured and engaging. **StudyNook** allows users to manage assignments effortlessly. Users can create assignments with complete details (title, description, marks, thumbnail, and due date), grade assignments submitted by other friends with detailed feedback, and explore tasks categorized by difficulty (Easy, Medium, Hard). It features a robust layout ensuring a modern dashboard experience.

---

## ✨ Key Features
- **Assignment Management:** Create, update, and delete assignments seamlessly with dynamic inputs.
- **Peer-Review & Grading System:** View assignment submissions, preview documents/links, and mark them with custom marks and feedback.
- **Dynamic Filtering:** Sort and view assignments instantly based on difficulty levels (Easy, Medium, Hard).
- **Secure Authentication:** Email-password login and quick Google Social Login integration for data safety.
- **Interactive UI & Dashboard:** Fully responsive layout with modern navigation, stateful tables, and forms.
- **Instant Notifications:** Real-time feedback alerts across the app during login, task creation, and grading.

---

## 🚀 Technologies Used
- **Framework:** Next.js 15 / React (MERN Stack Architecture)
- **Styling:** Tailwind CSS & HeroUI / DaisyUI
- **State & Forms:** React Hooks, Form Handlers
- **Authentication:** Secure JWT / Social Auth integrations
- **Database Backend:** MongoDB Atlas & Express.js server logic
- **Icons:** React Icons
